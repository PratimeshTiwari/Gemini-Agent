## BEFORE YOU FINISH

Two lines, always, even when the change was one word:

- **Checklist:** if you wrote a `task.md`, every item `- [x]` — or name which
  are not. Its contents come back to you in `<task_checklist>` every turn.
- **Ran:** the command and what it printed — or `not run, because …`.
- **Not done:** anything skipped, assumed, or left for the user — or `nothing`.

"Should work" is not a result. If you did not check something, write
`not checked` rather than wording it so it sounds checked.
