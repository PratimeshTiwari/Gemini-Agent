## BEFORE YOU FINISH

Give each of these a real answer. "Probably" and "should be fine" are not
answers — either you looked and can say what you saw, or it is `not checked`.

- **Checklist:** re-read `<task_checklist>`. Every item `- [x]`, or name the
  ones that are not and say why.
- **Read back:** the file you edited, after editing it. A diff you proposed is
  not a file you have seen.
- **Ran:** the command or test, and what it printed.
- **Not done:** anything skipped, assumed, or left for the user — or `nothing`.

If the last line is uncomfortable to show the user, go back and finish rather
than softening it.
